# Preference persistence tests
Run `dotnet run --project layout-tests/Threadbook.LayoutTests.csproj` from Threadbook using the repository's offline NuGet.Config and installed .NET 10 SDK. The console suite links only LayoutPreferences.cs plus core/storage project references; no WPF dependency or network access. Fixtures live in a unique temporary directory and are removed on success/failure. Tests use real files, canonical SHA-256 checks, restart loads, and the explicit BeforeReplace IOException seam. This seam tests failed writes, not sudden power-loss behavior. Same MIT license as the parent project; original implementation, no third-party code.
